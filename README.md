# Service Lab

요구사항을 직접 구현하고 검증하며, 하나의 서비스로 발전시키는 개발 실습 프로젝트다.

프론트엔드와 백엔드를 연결하고, 학습한 개념을 실제 기능에 적용한다. 각 실습은 별개의 예제로 분리하지 않고, 기존 기능을 확장하거나 개선하는 방식으로 진행한다.

## 기술 스택

- Java 21
- Spring Boot 4.1.1
- Spring Data JPA
- PostgreSQL
- Gradle

## 진행 방식

- 주차별로 요구사항을 정하고, 필요한 개념과 구현 계획을 문서로 정리한다.
- 직접 코드를 작성하며 동작 원리를 이해하는 연습을 한다.
- 정상 동작과 실패 상황을 검증하고, 설계 판단과 결과를 기록한다.
- 각 주차의 기능을 기존 기능에 연결하며 하나의 서비스로 발전시킨다.

주차별 요구사항과 실습 기록은 별도 문서로 관리하고, README에 링크를 추가한다.
