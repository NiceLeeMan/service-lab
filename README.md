# Service Lab

요구사항을 직접 구현하고 검증하며, 하나의 서비스로 발전시키는 개발 실습 프로젝트다.

프론트엔드와 백엔드를 연결하고, 학습한 개념을 실제 기능에 적용한다. 각 실습은 별개의 예제로 분리하지 않고, 기존 기능을 확장하거나 개선하는 방식으로 진행한다.

## 기술 스택

- Java 21
- Spring Boot 4.1.1
- Spring Data JPA
- PostgreSQL
- Gradle

## 진행 방식

1. 구현할 요구사항과 확인할 동작을 정한다.
2. 필요한 개념을 학습하고 직접 구현한다.
3. 정상 동작과 실패 상황을 검증한다.
4. 구현 과정의 판단과 결과를 기록한다.
5. 다음 요구사항을 기존 서비스에 연결한다.

실습은 주차별로 진행하며, 각 주차의 요구사항과 구현·검증 기록은 별도 문서로 관리한다. 해당 문서 링크는 이 README에 순차적으로 추가한다.
